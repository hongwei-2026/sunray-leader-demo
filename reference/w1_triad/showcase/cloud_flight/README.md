# cloud_flight 演示证据（负责人私有参考）

来自组织仓草稿 PR #205 的 `showcase/cloud_flight/`，**不得**合入民大组织仓库给学生抄。

内容是参考算法在云端跑八字/方形/四圈时的：
- `*.result.json`：时长、跟踪误差、净空等摘要
- `*.csv` / `world_positions.csv`：轨迹采样
- `*.plan.json`：规划点列
- `*.png` / `*.log`：截图与日志

算法本体仍在本目录上一级的 `student.py` / `flight_paths.py`。
学生作业只看组织仓 `tasks/w1_triad` + JSONL 接口，不看这里。
